Taller de Programación Orientada a Objetos (POO)

## Descripción
Este proyecto contiene el desarrollo de un taller de Programación Orientada a Objetos utilizando JavaScript. 
Está compuesto por diez ejercicios prácticos en los que se aplican conceptos de POO y validaciones para controlar posibles errores.

## Objetivo
Practicar los conceptos de Programación Orientada a Objetos mediante la creación de clases, objetos y métodos, además de implementar validaciones para evitar errores en cada ejercicio.

## Ejercicios realizados
1. Cuentas bancarias.
2. Carrito de compras.
3. Vehículos y viajes.
4. Citas médicas.
5. Empleados y nómina.
6. Biblioteca y préstamos.
7. Pedidos de restaurante.
8. Servicios de reparación del hogar.
9. Reservas turísticas.
10. Adopción y cuidado de mascotas.

## Validaciones
En cada ejercicio se realizaron validaciones para controlar situaciones incorrectas, como datos negativos, registros duplicados, información inexistente, cantidades inválidas y otras situaciones que podrían generar errores en el funcionamiento del programa.

## Tecnologías utilizadas
- JavaScript.
- Visual Studio Code.
- Code Runner.
- GitHub para almacenar y organizar el proyecto.
